# Villa Toscana

Responsive web and mobile-friendly restaurant website for Villa Toscana, built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and Lucide icons.

## Live Website

View the site here:

https://villa-toscana-two.vercel.app/

## About

Villa Toscana is a premium showcase website concept for an Italian fine dining restaurant. It is designed for desktop and mobile browsers, with responsive sections, elegant visuals, smooth motion, menu highlights, atmosphere-driven content, and clear reservation calls to action.

The project presents the restaurant's identity, culinary positioning, dining experience, menu sections, testimonials, location details, and booking prompts in a refined modern web experience.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Next.js, usually `http://localhost:3000`.

## Build

```bash
npm run build
```
